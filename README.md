1주차 - 황승희
알고리즘 (승률 계산)
- 포커 족보 10종(로열 플러시~하이카드) 판정을 구현하고, 내 카드 2장만 보고 커뮤니티 카드 3장과 상대 패를 랜덤으로 뽑는 몬테카를로 시뮬레이션(2만 회)으로 내 승률을 계산함
- 승률을 상대 인원 기준의 공평한 몫과 비교해 카드 평가(매우 좋음~매우 약함)와 포기/계속 추천 문구를 출력함
- 카드는 랭크+무늬 대문자(예: "AS", "10H")로 입력하며, `analyze(["AS", "KH"])`로 호출

### 함수 설명

| 함수 | 설명 |
|---|---|
| `norm(card)` | YOLO가 넘겨준 카드 표기를 덱 표기와 맞춤 (대문자로 통일, `T`는 `10`으로 변환) |
| `rank5(cards)` | 카드 5장의 족보를 `(족보번호, 키커...)` 튜플로 반환. 튜플이 클수록 강한 패이며, A-2-3-4-5 스트레이트도 인정 |
| `best_rank(cards)` | 5장 이상일 때 그중 가장 강한 5장 조합의 족보를 반환 |
| `my_win_rate(my_cards)` | 내 카드 2장만 알고, 커뮤니티 카드 3장과 상대 패를 랜덤으로 뽑아 2만 번 시뮬레이션해서 승률을 추정 (무승부는 0.5승) |
| `describe_hand(my_cards)` | 내 카드 2장의 특징(포켓 페어, 같은 무늬, 연속된 숫자, 높은 카드)을 한 줄로 설명 |
| `advice(rate)` | 승률을 공평한 몫(1/전체 인원)과 비교해 카드 평가와 행동 추천(베팅/계속/포기)을 반환 |
| `analyze(my_cards)` | 카드 검사(2장, 중복, 표기 오류) 후 위 함수들을 호출해 결과를 출력하는 진입 함수 |
## 🗓️ 1주차 작업 내역
**작업자:** 전수민
### 📁 주요 구현 내용

* **`download_data.py` (데이터셋 구축)**
  * **Roboflow API**를 연동하여 프로젝트에 필요한 포커 카드 원본 데이터셋을 로컬 환경에 자동으로 다운로드하는 환경 세팅 스크립트입니다. 
  * 개별 발급받은 개인 API Key를 사용하여 안전하게 데이터를 가져오도록 구성했습니다.

* **`train.py` (모델 학습)**
  * 준비된 데이터셋을 바탕으로 YOLO 모델을 훈련시키는 핵심 학습 스크립트입니다.
  * 전체 에포크(Epoch) 학습을 무사히 마치면, 인공지능의 뇌 역할인 최적의 가중치 파일(`best.pt`)을 생성하여 저장합니다.

* **`Final_project.py` (인식 성능 테스트)**
  * 학습이 완료된 최종 모델(`best.pt`)을 불러와 실제 카드 인식 성능을 검증하는 테스트 스크립트입니다.
  * 테스트용 이미지(`test_image.jpg`)를 입력하면, 모델이 사진 속 카드의 위치(Bounding Box)를 찾고 종류(클래스명)와 확률을 판별하여 시각화된 결과물을 출력합니다.

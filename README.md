1주차 - 황승희
알고리즘 (승률 계산)
- 포커 족보 10종(로열 플러시~하이카드) 판정을 구현하고, 내 카드 2장만 보고 커뮤니티 카드 3장과 상대 패를 랜덤으로 뽑는 몬테카를로 시뮬레이션(2만 회)으로 내 승률을 계산함
- 승률을 상대 인원 기준의 공평한 몫과 비교해 카드 평가(매우 좋음~매우 약함)와 포기/계속 추천 문구를 출력함
- 카드는 랭크+무늬 대문자(예: "AS", "10H")로 입력하며, `analyze(["AS", "KH"])`로 호출

### 함수 설명

| 함수 | 설명 |
|---|---|
| `norm(card)` | YOLO가 넘겨준 카드 표기를 덱 표기와 맞춤 (대문자로 통일, `T`는 `10`으로 변환) |
| `rank5(cards)` | 카드 5장의 족보를 `(족보번호, 키커...)` 튜플로 반환. 튜플이 클수록 강한 패이며, A-2-3-4-5 스트레이트도 인정 |
| `best_rank(cards)` | 5장 이상일 때 그중 가장 강한 5장 조합의 족보를 반환 |
| `my_win_rate(my_cards)` | 내 카드 2장만 알고, 커뮤니티 카드 3장과 상대 패를 랜덤으로 뽑아 2만 번 시뮬레이션해서 승률을 추정 (무승부는 0.5승) |
| `describe_hand(my_cards)` | 내 카드 2장의 특징(포켓 페어, 같은 무늬, 연속된 숫자, 높은 카드)을 한 줄로 설명 |
| `advice(rate)` | 승률을 공평한 몫(1/전체 인원)과 비교해 카드 평가와 행동 추천(베팅/계속/포기)을 반환 |
| `analyze(my_cards)` | 카드 검사(2장, 중복, 표기 오류) 후 위 함수들을 호출해 결과를 출력하는 진입 함수 |

2주차 - 황승희
- 카드 표기 수정 예: As, 10h
- yolo 연동
- 커뮤니티 카드가 4~5장에서도 확률을 보여주도록 수정
- 입력 검증

### 함수 설명

| 함수 | 설명 |
|---|---|
| `norm()` | YOLO에서 인식한 카드 이름을 알고리즘에서 사용하는 표준 형식(As, Kh 등)으로 변환 (앞은 그대로, 뒤는 소문자로 통일) |
| `my_win_rate()` | 공개된 커뮤니티 카드 장수에 따라 남은 카드와 상대 패를 무작위 추출하여 승률 계산 |
| `cards_from_yolo()` | YOLO 탐지 결과에서 카드 종류와 Confidence를 추출하고 중복 클래스 및 낮은 신뢰도 결과를 필터링 |
| `my_win_rate(my_cards)` | 내 카드 2장만 알고, 커뮤니티 카드 3장과 상대 패를 랜덤으로 뽑아 2만 번 시뮬레이션해서 승률을 추정 (무승부는 0.5승) |
| `analyze_yolo()` | OLO 인식 결과를 승률 계산 알고리즘에 전달하는 연동 함수 |
| `analyze()` | 플레이어 카드와 커뮤니티 카드의 유효성, 장수, 중복 여부를 검증하고 종합 분석 |


### 변수 설명

| 변수 | 설명 |
|---|---|
| `MIN_CONF` | YOLO 카드 인식 최소 신뢰도 기준을 0.1로 설정 |
| `STAGE_NAMES` | 커뮤니티 카드 장수에 따라 프리플랍, 플랍, 턴, 리버 구분 |
| `board` | 현재 공개된 커뮤니티 카드 |

## 🗓️ 1주차 작업 내역
**작업자:** 전수민
### 📁 주요 구현 내용

* **`download_data.py` (데이터셋 구축)**
  * **Roboflow API**를 연동하여 프로젝트에 필요한 포커 카드 원본 데이터셋을 로컬 환경에 자동으로 다운로드하는 환경 세팅 스크립트입니다. 
  * 개별 발급받은 개인 API Key를 사용하여 안전하게 데이터를 가져오도록 구성했습니다.

* **`train.py` (모델 학습)**
  * 준비된 데이터셋을 바탕으로 YOLO 모델을 훈련시키는 핵심 학습 스크립트입니다.
  * 전체 에포크(Epoch) 학습을 무사히 마치면, 인공지능의 뇌 역할인 최적의 가중치 파일(`best.pt`)을 생성하여 저장합니다.

* **`Final_project.py` (인식 성능 테스트)**
  * 학습이 완료된 최종 모델(`best.pt`)을 불러와 실제 카드 인식 성능을 검증하는 테스트 스크립트입니다.
  * 테스트용 이미지(`test_image.jpg`)를 입력하면, 모델이 사진 속 카드의 위치(Bounding Box)를 찾고 종류(클래스명)와 확률을 판별하여 시각화된 결과물을 출력합니다.
  

-포커 승리 확률 계산기 실행 bat파일 생성함

## 🗓️ 2주차 작업 내역
**작업자:** 전수민

이번 2주차에는 1주차에 구축한 기본 파이프라인을 바탕으로 본격적인 모델 학습을 진행하고, 실제 테스트 과정에서 도출된 미흡한 점을 보완하는 단계를 거쳤습니다.

### 📁 주요 구현 및 개선 내용

* **초기 모델 학습 및 한계점 도출**
  * 구축한 데이터셋과 학습 스크립트(`train.py`)를 활용해 충분한 횟수(Epochs)로 모델 학습을 완료하고 최적의 `best.pt` 가중치 파일을 확보함.
  * 완성된 모델로 실제 테스트를 진행한 결과, 특정 카드나 환경에서 인식률이 다소 미흡하거나 오인식되는 한계점을 발견함.

* **추가 데이터셋 확보 및 Fine-Tuning (이어서 학습)**
  * 기존 데이터셋의 부족한 부분을 보완하기 위해 새로운 카드 데이터셋을 추가로 수집 및 병합함.
  * 기존에 학습된 `best.pt` 가중치를 불러온 상태에서 추가 데이터를 반영한 **파인튜닝(Fine-Tuning / 이어서 학습)**을 진행하여 모델의 식별 정확도와 완성도를 한층 더 높임.
  


# 오늘 작업 내용

### 1. 실시간 웹캠 기능 구현 및 구조 개선
- 기존 사진 업로드 방식에서 실시간 웹캠을 사용하는 방식으로 변경
- `streamlit-webrtc`를 활용하여 웹캠 영상을 웹 화면에 출력하도록 구현
- 웹캠 영상 출력과 YOLO 카드 인식 과정을 분리
- `VideoProcessorBase`의 `recv()`에서 최신 프레임을 저장하고 원본 영상을 반환하도록 구성

### 2. YOLO 카드 인식 기능 연결
- 학습한 YOLO11m 모델(`best.pt`)을 웹캠 영상에 연결
- 카드의 세로 좌표를 기준으로 내 카드와 커뮤니티 카드를 구분하도록 구현
- 카드 검출 시 바운딩 박스와 카드 종류, 신뢰도를 화면에 표시
- 중복으로 검출된 카드는 신뢰도가 높은 결과만 남기도록 처리

### 3. 실시간 카드 정보 갱신 기능 개선
- 최근 YOLO 인식 결과를 저장하는 카드 안정화 기능 구현
- 동일한 카드 구성이 반복해서 인식되면 오른쪽 카드 정보에 반영하도록 구성
- 카드가 모두 사라졌을 때 이전 인식 결과가 남는 문제를 발견하고 수정 방향 확인

### 4. 카드 이미지 출력 오류 확인
- 카드 이미지를 Base64 문자열로 변환하여 HTML에 삽입하는 기존 출력 방식 확인
- Base64 이미지 데이터가 오류 화면에 길게 출력되는 문제 확인
- `st.image()`를 활용하여 이미지 파일을 직접 출력하는 방식으로 변경 방향 결정

### 5. YOLO 실시간 처리 속도 개선 검토
- 0.6초 간격으로 최신 웹캠 프레임을 분석하도록 구성
- YOLO 입력 이미지 크기를 기존 1280에서 960으로 줄이는 최적화 방안 검토
- 카드 인식 속도와 정확도 사이의 균형을 고려하여 추가 테스트 필요

### 6. 향후 작업
- 카드 이미지 출력 방식 수정 후 오류 확인
- 오른쪽 내 카드 및 커뮤니티 카드 정보 갱신 테스트
- 웹캠 영상과 YOLO 인식 속도 확인
- 실시간 카드 인식 결과를 기반으로 승률 분석이 정상적으로 갱신되는지 테스트
